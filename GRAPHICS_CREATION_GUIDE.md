# 📊 GRÁFICO 1: DIVERGENCE METER 75% ⭐⭐⭐

## Diseño Visual:

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│        CIVILIZATIONAL DIVERGENCE DETECTED           │
│                                                     │
│    ████████████████████████████████████░░░░░░░░░    │
│                   75%                               │
│                                                     │
│    LOW         MODERATE         HIGH    EXTREME     │
│    0%            25%            50%        75%      100%│
│                                                     │
│           16 BLIND SPOTS IDENTIFIED                 │
│        8 Western  •  8 Eastern                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### PowerPoint - Paso a Paso:

**1. Crear nueva presentación:**
- Abrir PowerPoint
- Seleccionar diseño: "En blanco"
- Tamaño: 1920x1080 (16:9)

**2. Fondo:**
- Click derecho → Formato de fondo
- Color: Negro o Azul oscuro (#0A0E27)

**3. Título:**
- Insertar → Cuadro de texto
- Texto: "CIVILIZATIONAL DIVERGENCE DETECTED"
- Fuente: Arial Bold, 48pt
- Color: Blanco o Celeste (#3A86FF)
- Centrado arriba

**4. Barra de progreso (75%):**

**Método 1 - Rectángulos:**
- Insertar → Formas → Rectángulo
- Tamaño: Ancho 800px, Alto 60px
- Color: Gris oscuro (#444444)
- Sin borde
- Copiar este rectángulo
- Cambiar color a: Naranja/Rojo (#FB5607 o #FF006E)
- Tamaño: Ancho 600px (75% de 800), Alto 60px
- Alinear a la izquierda del rectángulo gris

**Método 2 - Barra de progreso animada:**
- Insertar → SmartArt → Proceso → Barra de progreso
- Personalizar al 75%

**5. Etiqueta "75%":**
- Cuadro de texto encima de la barra
- Fuente: Arial Black, 72pt
- Color: Blanco
- Centrado

**6. Escala (0% - 100%):**
- Cuadros de texto pequeños debajo de la barra
- "LOW" "MODERATE" "HIGH" "EXTREME"
- "0%" "25%" "50%" "75%" "100%"
- Fuente: Arial, 18pt
- Color: Gris claro

**7. Estadística de blind spots:**
- Cuadro de texto abajo
- "16 BLIND SPOTS IDENTIFIED"
- Fuente: Arial Bold, 36pt
- Color: Blanco

- Segundo cuadro:
- "8 Western  •  8 Eastern"
- Fuente: Arial, 24pt
- Color: Gris claro

**8. Exportar:**
- Archivo → Guardar como → PNG
- Nombre: `graphic_01_divergence_meter_75.png`
- Calidad: Alta (300 DPI)

# 🐍 ALTERNATIVA: PYTHON SCRIPTS

Si prefieres generar los gráficos con código, aquí está el script:

## Script Python - Divergence Meter

```python
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches

fig, ax = plt.subplots(figsize=(12, 6), facecolor='#0A0E27')
ax.set_facecolor('#0A0E27')

# Title
ax.text(0.5, 0.9, 'CIVILIZATIONAL DIVERGENCE DETECTED',
        ha='center', va='center', fontsize=32, color='#3A86FF',
        weight='bold', transform=ax.transAxes)

# Progress bar background
bar_bg = mpatches.Rectangle((0.1, 0.4), 0.8, 0.15,
                             facecolor='#333333', edgecolor='none')
ax.add_patch(bar_bg)

# Progress bar fill (75%)
bar_fill = mpatches.Rectangle((0.1, 0.4), 0.6, 0.15,
                               facecolor='#FF006E', edgecolor='none')
ax.add_patch(bar_fill)

# 75% label
ax.text(0.5, 0.475, '75%', ha='center', va='center',
        fontsize=64, color='white', weight='bold', transform=ax.transAxes)

# Scale labels
scale_labels = ['LOW\n0%', 'MODERATE\n25%', 'HIGH\n50%', 'EXTREME\n100%']
scale_positions = [0.1, 0.3, 0.5, 0.9]
for label, pos in zip(scale_labels, scale_positions):
    ax.text(pos, 0.25, label, ha='center', va='top',
            fontsize=14, color='#AAAAAA', transform=ax.transAxes)

# Blind spots stats
ax.text(0.5, 0.15, '16 BLIND SPOTS IDENTIFIED',
        ha='center', va='center', fontsize=24, color='white',
        weight='bold', transform=ax.transAxes)
ax.text(0.5, 0.08, '8 Western  •  8 Eastern',
        ha='center', va='center', fontsize=18, color='#AAAAAA',
        transform=ax.transAxes)

ax.set_xlim(0, 1)
ax.set_ylim(0, 1)
ax.axis('off')

plt.tight_layout()
plt.savefig('graphic_01_divergence_meter_75.png', dpi=300, bbox_inches='tight')
plt.show()
```
